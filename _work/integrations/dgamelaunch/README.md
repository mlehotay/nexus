# dgamelaunch Integration Records

Nexus owns the FLEY workflow for dgamelaunch and the Floating Eye NetHack
variant. The upstream-derived `../dgamelaunch` checkout remains free of FLEY
`_work/` and `AGENTS.md` files.

This directory preserves records migrated from `../dgamelaunch/_work/` on
2026-08-23:

- `setup-notes.md`: historical dgamelaunch installation and configuration
  reference.
- `context.md`: repository, host, runtime, and authority context captured before
  workflow delegation was established.
- `workflow-boundary-history.md`: history of the abandoned attempt to install
  FLEY workflow directly in dgamelaunch.
- `legacy-repo-workflow.md`: the exact former local workflow copy, retained as
  migration evidence rather than active Nexus policy.
- `source-codex-log.md`: the historical dgamelaunch-local Codex record.

The live-data backup runbook moved separately to
`../../../../site-ops/_work/notes/illithid-data-preservation.md`, where Illithid host
operations are authoritative.

These files are references. Active Nexus work belongs in `../../tasks.csv` and
`../../plans/`; active Illithid host work belongs in the site-ops dashboards.
