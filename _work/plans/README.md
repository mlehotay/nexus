# Nexus Plans

Plans describe work fronts that may span multiple tasks or sessions.

Use a plan when work needs context, constraints, acceptance criteria, or a
durable handoff between you and Codex. Keep plans small and revise them as the
project teaches us what is actually needed.

The dashboard is `plans.csv`.

Status values:

- `todo`
- `doing`
- `blocked`
- `done`
- `dropped`

Priority values:

- `P0` urgent or blocking
- `P1` milestone-critical
- `P2` useful soon
- `P3` later or housekeeping
